# Rust with Large Language Models

I'm trying to learn some Rust using an LLM as a tutor/assistant.
This repo supports the ongoing (as of July 2024, now finished) [blog series](https://sebszyller.com/blog/2024/rustwithllmsstart).

Check out the [docs](docs/interactions.md) for some annotated examples of interactions.

As a capstone project I built a [TUI LLM chat](https://github.com/sebszyller/tui-llm-chat-rs).
